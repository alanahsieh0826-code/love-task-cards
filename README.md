# 愛的任務卡（注音版）

在餐廳就能當場完成的 24 個小任務卡，給小朋友送給最愛的人。

- 網頁版：https://alanahsieh0826-code.github.io/love-task-cards/
- 左邊可以改任務文字、插圖和稱呼（預設「最愛的人」），注音會自動加上。
- 按「列印」印成 2 張 A4，每張 2×6 共 12 張小卡（每張約 7×4.7 公分），沿虛線剪開。列印時請選「實際大小 / 100%」並勾選「背景圖形」。

`愛的任務卡.html` 是圖片內嵌的單一檔案版本，下載後直接用瀏覽器打開即可（需要網路載入注音字型）。

注音字型：[Bpmf Huninn（粉圓注音版）](https://fontsource.org/fonts/bpmf-huninn)，SIL OFL 1.1 授權。
